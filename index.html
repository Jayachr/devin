Hello to devin

A sandbox repository for practicing Git workflows.

What this repo is for

Branching, rebasing, and resolving merge conflicts — rehearsed in a place where nothing breaks. There is no application code here, only throwaway files.

Try it

git clone https://github.com/Jayachr/devin.git
cd devin

git checkout -b my-branch
echo "some change" >> notes.txt
git add notes.txt && git commit -m "practice commit"

git rebase main
git checkout main && git merge my-branch
